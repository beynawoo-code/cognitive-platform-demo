# 认知平台 · L1 业务工作流

> **TL;DR**：现网主航道是 **提报/发布 → 审核上架 → 门户信息流消费与互动 → 课程/考试 → 积分兑换与激励 → 后台复盘**。门户服务全员；后台按菜单码拆运营职责。本版只画现网已有入口的链路。

## 端到端总览

```text
触发（员工/导师/运营）
  → 生产（提报 BDA / 提报素材 / 官方发布 / 组课组卷）
  → 治理（待审 / 发布 / 下线 / 上榜 / 奖金）
  → 分发（首页四 Tab + 搜索筛选 + 话题）
  → 消费（详情 · 有用/收藏/评论 · 课程进度 · 答题）
  → 触达（站内信）
  → 激励（积分/奖金/勋章/目标 · 商城兑换）
  → 复盘（提报统计 · 用户 · 目标额度）
```

外部交接（虚线）：ERP 主壳（登录/菜单/SSO）· user 服务 · digitize JPC · 钉钉免登 · OSS 附件 · 考试超时等定时任务。

## 路径 1 · 专业素材提报上架

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 门槛 | MENTOR | 门户「提报素材」调导师校验接口 | 是否导师 + 岗位/价值点 |
| 填写 | MENTOR | `/submit/material` 填内容（Quill） | 草稿或提交 |
| 治理 | OPS / GROWTH | 后台「素材管理」审核、上下线 | 已发布素材 |
| 分发 | EMP | 首页 **专业** Tab 消费 | 卡片/详情 |
| 互动 | EMP | 有用 / 收藏 / 评论 | 互动计数、消息 |

对应后台：素材管理；提报内容管理（JPC/分享详情子页）。

## 路径 2 · BDA 提报与激励

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 填写 | EMP | 门户「提报 BDA」C-B-A 结构 | 草稿(6) 或提交发布(2) |
| 审核 | OPS / BP | 后台 BDA：上级处理中 → BP 处理中 → 审核完成 | 审核状态 |
| 上架 | OPS | 发布 / 下线 / 上榜 | CBDA 信息流可见 |
| 激励 | BP / OPS | 奖金/积分发放状态 | 流水 |
| 消费 | EMP | 首页 **CBDA案例** Tab | 详情、上榜标记 |

## 路径 3 · 官方发布与活动

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 创作 | OPS | 后台新建发布内容（文件/图文/视频） | 发布稿 |
| 活动 | OPS | 活动管理配置 | 活动位 |
| 消费 | EMP | 首页 **官方发布** Tab | 详情 |
| 话题 | OPS | 话题管理 | 板块标签，挂到专业等内容 |

## 路径 4 · 课程学习

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 组课 | LEARN | 后台课程管理（文档/图文/视频） | 已发布课程 |
| 发现 | EMP | 首页 **课程** Tab | 列表卡片 |
| 学习 | EMP | 课程详情、进度上报 | 进度 |
| 互动 | EMP | 有用/收藏等（与内容共用互动模型） | 计数 |

## 路径 5 · 考试闭环

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 题库 | LEARN | 试题管理；可选 AI 试题生成页（现网页，能力完整度未在本版展开） | 试题 |
| 主题 | LEARN | 考试主题 | 主题与范围 |
| 组卷 | LEARN | 考试管理：创建/编辑/复制/查看 | 考试 |
| 应考 | EMP | 门户考试列表 → 简介 → 答题 → 成绩 → 排行 | 答卷、排名 |
| 提题 | EMP | 提报考题 / 编辑考题 | 待审试题（运营侧试题管理承接） |

超时自动交卷等批处理在 digitize 侧，门户只消费结果。

## 路径 6 · 信息流消费、互动与消息

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 发现 | EMP | 四 Tab + 筛选/排序/搜索 | 信息流 |
| 阅读 | EMP | 专业/CBDA/课程/发布详情 | 浏览 |
| 互动 | EMP | 有用、一般、收藏、评论 | 记录 |
| 触达 | EMP | 消息中心（全部/点赞/评论/收藏/系统等 Tab） | 未读、深链 |

## 路径 7 · 积分兑换与个人资产

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 入账 | OPS / PTS / 系统 | 内容激励、目标、批量调整等 | 积分/奖金流水 |
| 商城 | EMP（需积分按钮权限） | 浏览商品、兑换、申请加积分 | 订单/申请 |
| 履约 | PTS | 商品管理、兑换订单领取、积分明细 | 履约状态 |
| 成长 | GROWTH / EMP | 勋章墙、铭牌、我的互动、目标额度 | 个人资产 |

门户「积分」「奖金」入口分别受 `cognition:cognition:app:minePoint` / `mineBonus` 门控。

## 路径 8 · 运营复盘（后台）

| 阶段 | 角色 | 动作 | 交付物 |
|------|:---:|------|--------|
| 人 | SYS | 用户管理 | 账号视图 |
| 量 | SYS | 提报统计、导入导出任务 | 报表/异步任务 |
| 目标 | GROWTH / SYS | 目标管理（额度/规则/发放） | 年度目标执行 |

## 与 L3 / L4 回写

- 每条路径节点均落在 L3 六个能力域之一。
- L4 门户顶栏与后台 19 页均可在上述路径找到使用场景。
- 现网路由未出现的环节不进入本图。
