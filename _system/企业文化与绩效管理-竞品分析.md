# 企业文化与绩效管理 · 竞品分析

| 项 | 说明 |
| --- | --- |
| **文档类型** | 竞品调研 / 选型参考 |
| **适用场景** | 研 + 工 + 贸 + 跨境；企业规模 **1000+**；需 **文化 + 绩效** 一体，并让员工 **透明了解晋升空间** |
| **关联产品** | 认知平台（VPSLP 专业成长、价值点、导师制等）与 HCM/EX 平台的边界参考 |
| **信息来源** | 厂商官网、公开对比文章、行业榜单；检索时间 **2026-10** |
| **免责声明** | 厂商案例与市场份额表述来自其营销材料，选型须以 POC、报价与合规评审为准 |

## 1. 核心结论

1. **没有单一产品**能同时完美覆盖「集团绩效 + 跨境合规 + 文化倾听 + 专业序列晋升可视化」；1000+ 研工贸跨境常见形态为 **1 套 HR 主平台 + 海外基地合规 HR + 文化/专业成长专项（含自研认知平台）**。
2. **晋升透明**的瓶颈多数在 **制度（序列 × 职级 × 任职资格）**，而非软件；系统价值在于把标准 **员工可见**，并与绩效、学习、盘点、薪酬 **同一套数据语言** 联动。
3. **国内主平台短名单**：**北森**（集团、多绩效模式、职级—盘点—薪酬闭环）> **飞书 People**（研发协同、OKR/绩效一体，制造/海外常需补模块）> **明基逐鹿 / 凯普**（海外工厂 MBO+PA、多账套合规）。
4. **国际参照**（英文团队或 UX 标杆）：**Lattice**（绩效 + Grow 职级轨道）、**Culture Amp**（倾听与 People Science）、**15Five**（持续 Check-in + 经理教练）。
5. **认知平台 / VPSLP 差异化位**：HCM 管「职级与考核流程」；认知平台管 **岗位价值点、素材与评估、导师辅导、LV 成长路径、CBDA/案例**——聚合为员工可读的 **专业晋升证据层**，与 HR 主数据对接而非替代。

## 2. 调研范围与定义

### 2.1 文化管理（本报告口径）

价值观与行为标准传播、员工倾听（Engagement / Pulse）、认可与激励、内部沟通与社区、雇主品牌与归属感、跨地域协同下的「公司奖励什么」。

### 2.2 绩效管理（本报告口径）

目标体系（KPI / OKR / BSC / MBO / 项目制等）、过程辅导与 1:1、多源评估与校准、结果应用（薪酬、晋升、盘点、PIP）、持续反馈与 AI 辅助评语/面谈。

### 2.3 晋升空间透明化（本报告口径）

员工能稳定回答：**当前职级 → 下一职级标准 → 已有证据 → 差距与建议行动 → 公司晋升规则说明**（透明标准与过程，**不**等于承诺晋升名额）。

### 2.4 市场三类形态

| 类型 | 代表 | 典型买家诉求 |
| --- | --- | --- |
| 员工体验 / 文化科学 | Culture Amp、Workvivo、Motivosity | 先听懂组织，再改行为 |
| 绩效 + 目标一体化 | Lattice、15Five、Leapsome、Betterworks、北森绩效云 | 考核流程 + OKR + 经理效能 |
| HR 全模块 / 协作入口 | 北森、SAP / Workday、飞书 People、钉钉/企微生态 | 战略—人事—绩效—薪酬一条链 |

## 3. 目标客户场景画像（1000+ 研工贸跨境）

| 特征 | 说明 |
| --- | --- |
| 组织 | 总部、研发中心、工厂/代工、海外子公司；矩阵与虚线汇报常见 |
| 序列 | 研发、工艺/质量、供应链、跨境运营（关务/物流/平台）、销售、职能 |
| 绩效 | 研发/职能偏 OKR 或项目；制造偏 KPI/MBO/计件；区域目标叠加 |
| 文化 | 价值观 + **专业标准** + 跨地域协同；不能只靠年终考核 |
| 跨境 | 多国薪酬/工时/语言；总部职级框架与本地岗位名称并存 |
| 核心诉求 | 文化 + 绩效 + **员工端可见的晋升路径与准备度** |

## 4. 「晋升透明」产品能力分层

| 层级 | 员工应看到什么 | 典型产品模块 |
| --- | --- | --- |
| 制度层 | 双通道（专业/管理）、职级表、晋升节奏说明 | 人事主数据、政策门户 |
| 标准层 | 当前 vs 下一职级：能力/行为/业绩差异（可观测） | 任职资格、Career Track、Grow |
| 证据层 | 绩效、目标、360、项目/认证、学习完成度 | 绩效云、OKR、LMS、测评 |
| 差距层 | 缺哪几条 + 建议（课程、轮岗、导师、项目） | IDP、发展计划、AI 推荐 |
| 机会层 | 内竞聘/开放岗位（可选）；继任名单通常不全员公开 | 内招、人才市场 |
| 文化层 | 认可、案例、价值点/CBDA，解释「奖励什么行为」 | EX、认可、**认知平台** |

**原则**：透明 = **标准透明、过程可追溯、结果可解释**；编制与名额仍由组织决策。

## 5. 国际竞品

### 5.1 第一梯队对比（Culture Amp / Lattice / 15Five）

| 维度 | Culture Amp | Lattice | 15Five |
| --- | --- | --- | --- |
| 基因 | 组织心理学 + 调研基准 | 结构化绩效 + OKR | 周 Check-in + 经理教练 |
| 文化 | **强**：全周期调研、基准、行动规划 | 中：调研/脉冲 + 认可 | 中：High Fives、Engage |
| 绩效 | 有，偏组织健康 | **强**：Review、360、校准、薪酬扩展 | 中：Review/OKR |
| 晋升可见 | 中（偏洞察） | **强**：Grow Career Tracks、能力矩阵、IDP | 中：Growth Plan |
| AI | Coach / 倾听行动 | Lattice AI | AMAYA / Spark |
| 规模甜区 | 500+ | 约 50～5000 | 约 &lt;100～1000 |
| 定价量级（公开参考） | 询价，约 $4.5～15+ PEPM | 约 $11～15 PEPM | 约 $4～16 PEPM |
| 适合 | 敬业度与公平感优先 | 一套搞定绩效+目标+职级 UX | 先养成每周对话 |

**海外 mid-market 速选**：

- 绩效 + OKR 闭环 → Lattice / Leapsome / Betterworks（1000+ 战略向）
- 倾听与组织诊断 → Culture Amp / Qualtrics EmployeeXM
- 低门槛持续反馈 → 15Five / Officevibe

### 5.2 Lattice Grow（晋升透明 UX 标杆）

- **Career Tracks**：序列、层级、关键能力、各层 scope/impact 期望。
- **与绩效联动**：Review、Goal、1:1、IDP 共用同一套能力语言。
- **设计原则**（官方）：按 scope、复杂度、影响力、协作、自主性区分层级，避免唯年限；公司级 / 管理级 / 职族级 / 角色级能力分层，避免过度堆砌。

### 5.3 专项品类

| 细分 | 产品 | 卖点 |
| --- | --- | --- |
| 认可与奖励 | Bonusly、Achievers、Awardco、Motivosity | 点对点认可、积分商城、IM 集成 |
| 内部沟通 / 文化社区 | Workvivo、Simpplr | 社交 intranet、直播、文化看板 |
| 绩效 + 学习 | Leapsome | OKR、Review、学习路径、薪酬工作流 |
| 战略 / 企业级 | Betterworks、Workday Peakon、SAP SuccessFactors | HCM + 战略解码 |
| EX 测量（研究型） | Qualtrics EmployeeXM、Glint | 复杂项目、文本分析 |

## 6. 国内竞品

### 6.1 北森 iTalent 一体化

| 项 | 内容 |
| --- | --- |
| **定位** | 一体化 HR SaaS：组织人事、招聘、绩效、薪酬、学习、测评、盘点 |
| **文化相关** | 文化激励、勋章荣誉、员工体验、AI 机器人（官网口径） |
| **绩效相关** | KPI/OKR/PBC/双轨/项目制等；战略解码、过程辅导、校准；结果联动薪酬、盘点、PIP |
| **晋升透明** | 职务职级体系、任职资格、人才盘点 SAFE、IDP、继任与晋升准备度；员工发展路径与成长档案叙事 |
| **研工贸/跨境** | 集团—区域—基地管控；制造/重工客户案例；钉钉/企微/飞书集成；海外统一管控 + 本地执行需与实施方确认 |
| **优势** | 1000+、多绩效模式、数据闭环、盘点与继任 |
| **风险** | 实施周期长；员工端「下一职级标准」体验依赖岗职体系梳理质量 |

### 6.2 飞书 People（OKR + 绩效 + 人事 + 招聘）

| 项 | 内容 |
| --- | --- |
| **定位** | 飞书协同内的 HR 套件，与文档/日历/Profile 深度集成 |
| **文化相关** | 目标透明、协作文化；弱独立「文化运营」模块 |
| **绩效相关** | 360、「手松手紧」校准、业绩/价值/潜力等多维评估 |
| **晋升透明** | 依赖企业自建职级；OKR 与 Profile 可见性高；职级页需与人事模块或外部 HCM 配合 |

| **缺口** | 工厂考勤薪酬、海外多账套常需 **凯普/明基/北森** 等补位 |

| 产品 | 文化 | 绩效 | 晋升 |

### 6.4 海外工厂 / 制造跨境层

| 产品 | 典型能力 | 与晋升透明关系 |
| --- | --- | --- |
| **凯普 eHR** | 多组织、多账套、海外工时合规、KPI/OKR、万人级制造客户 | 移动端查绩效；**全球职级叙事**建议总部主数据在北森/飞书 |

业财一体客户的 HR 套件；绩效与组织模块随 ERP 销售，适合已有 ERP 深度绑定、HR 数字化诉求弱于业财的场景。

## 8. 推荐架构与短名单（1000+ 研工贸跨境）

### 8.1 推荐组合（务实默认）

```text
HR 主平台（北森 或 飞书 People）
    → 职级体系 + 绩效 + 盘点 + 薪酬联动
海外基地（凯普 eHR / 明基逐鹿）
    → 合规考勤薪酬 + MBO/PA + 移动自助
文化 & 专业成长（认知平台 VPSLP + 可选 Culture Amp/Workvivo）
    → 价值点、导师、LV、案例/CBDA、认可与勋章
```

### 8.2 决策树

| 若企业… | 建议 |
| --- | --- |
| 已深度飞书，研发&gt;50%，制造外包轻 | **飞书 People 为主** + 补职级/盘点或北森人事 |
| 集团管控 + 工厂 + 多绩效 + 薪酬联动 | **北森为主** + 海外 **凯普/明基** |
| 欧美管理者多，要 Career Track UX | 主干国内 HCM，**参照 Lattice Grow** 做员工职级页 |
| 敬业度差、职级已有但信任低 | **Culture Amp 或北森调研+盘点** 后再推透明职级 |
| 强调专业认知与 VPSLP | HCM 管「级」；**认知平台** 管「价值点能力与证据」 |

## 9. 行业落地要点（晋升透明专项）

1. **序列**：技术研发、工程技术/制造、跨境业务、职能；每条 **P/M 双通道**。
2. **绩效映射**：同一职级语言下，不同模板（研发 OKR vs 工厂 MBO/KPI）。
3. **任职资格 = 晋升说明书**：scope / impact / 协作 / 专业深度，可观测、可举证。
4. **员工主页建议四块**：当前职级；下一职级标准对比；本期证据聚合；IDP/导师/学习建议。
5. **跨境**：总部统一职级码 + 海外本地岗位名；移动查绩效与职级。
6. **文化挂钩**：价值观进 360 或价值点评估；认可补充「被看见」，不替代职级标准。

### 9.1 实施顺序

1. 序列职级、任职资格、晋升规则（HR + 业务，3～6 个月）。
2. 系统：人事主数据 → 绩效挂职级 → 员工自助「我的发展」。
3. 盘点/继任（关键岗位试点）→ IDP 与准备度。
4. 认知平台：价值点/导师/案例写入发展证据。
5. 跨境：同一职级码、分模板考核。

## 10. 与认知平台（VPSLP）的分工

| 层级 | HCM / EX | 认知平台 VPSLP |
| --- | --- | --- |
| 职级、编制、晋升流程 | ● 主责 | 展示/跳转，不替代审批 |
| 绩效考核、校准、薪酬 | ● 主责 | 绩效 S、提报等内容可 **引用** 为证据 |
| 价值点评估、素材学习、考题 | 弱 | ● 主责 |
| 导师制、辅学员进度 | 弱 | ● 主责（导师工作台） |
| LV 路径、勋章、CBDA/案例 | 弱 | ● 主责 |
| 员工「我的晋升空间」聚合页 | 职级与盘点 | **价值点差距 + 学习 + 导师反馈** |

**集成建议**：员工 ID、职级、序列、当期绩效结果由 HCM 同步；认知平台回写价值点等级、导师评价、素材贡献至 **人才档案**（API 或数据中台）。

## 11. 趋势（2025–2026）

- 考核从「年终」→ 持续目标 + 微反馈 + AI 评语/面谈提纲。
