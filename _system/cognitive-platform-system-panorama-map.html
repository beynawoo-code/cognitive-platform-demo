系统边界与定位
做 / 不做 / 跨域

什么是认知平台。成长平台的基石，供给与学习的操作系统；端到端关注专业成长（VPSLP：轻量级、导师制、自助式，评估、丰富供给、融入实战）与职业成长（务实：新挑战 / 高绩效 / 晋升节奏 / 收入结构；务虚：心理安全 / 自我认知 / 心流），把个人岗位经验转化进组织，专注成长效率。

只做 员工在门户发现、提报、学习、考试、互动、兑换；运营在 ERP 后台审核、组卷、激励与积分履约。
不做 组织账号主数据、广告投放、订单履约、财务过账、通用项目管理。
跨域 鉴权菜单归 ERP systemCode=cognition；业务数据归 digitize；门户独立站，后台 Wujie。
